# Benchmark scripts

Available WP-00 helpers:

- acquisition and integrity checker for every manifest-referenced file
- controlled-shift fixture generator with exact sub-pixel truth
- split-leakage checker for protected split roles
- benchmark runner producing content-addressed, schema-valid aggregate and
  per-scene reports, including failed and rejected scenes
- route-matrix and claim-ledger validation; a numerical claim needs an
  immutable `brr-sha256-...` report ID
