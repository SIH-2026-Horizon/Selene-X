# ADR-0012: IIRS thermal/structural processing and unsupported-band policy

- **Status:** proposed
- **Date:** not yet decided
- **Blocks:** WP-02 IIRS adapter; WP-05 IIRS branch; SIH-compliant status
- **Related decisions:** D-003, D-004, R-005

## Context

IIRS is a cross-spectral instrument with a thermally influenced range, bad bands, and an unvalidated geometry path. It gets a separate thermal and structural branch and is never synthesised into a panchromatic image. Its geometry validation status must be honest and machine-readable.

## Decision

Not yet made. This ADR must be accepted before the code it governs is merged
(implementation plan section 5.3).
