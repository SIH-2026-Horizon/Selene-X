# ADR-0008: Eligibility mask and spatial-coverage definition

- **Status:** proposed
- **Date:** not yet decided
- **Blocks:** WP-07 selection; WP-09 coverage metrics and gates
- **Related decisions:** R-007

## Context

Coverage is only meaningful over physically eligible valid overlap. The definition must record why each excluded cell is ineligible, must place non-maximum suppression before coverage scoring, and must prevent derived points from occupying measured cells.

## Decision

Not yet made. This ADR must be accepted before the code it governs is merged
(implementation plan section 5.3).
