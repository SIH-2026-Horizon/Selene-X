# ADR-0015: Loopback-only versus authenticated network service boundary

- **Status:** proposed
- **Date:** not yet decided
- **Blocks:** WP-10 API deployment; WP-11 security evidence
- **Related decisions:** 

## Context

The development API is unauthenticated. Binding beyond loopback without minimally scoped credentials and one centralised authorisation hook would expose an unprotected processing service. Institutional identity remains a productionisation item.

## Decision

Not yet made. This ADR must be accepted before the code it governs is merged
(implementation plan section 5.3).
