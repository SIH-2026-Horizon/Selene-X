# ADR-0009: Adjustment parameterization and observability limits

- **Status:** proposed
- **Date:** not yet decided
- **Blocks:** WP-08 adjustment
- **Related decisions:** R-009

## Context

A pushbroom adjustment can absorb matching error into unobservable parameters and look excellent in sample. The parameter set starts limited and observable, and grows only when residual diagnostics and information-rank tests justify it.
